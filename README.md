# Git for DevOps

A practical learning repository for using Git in day-to-day DevOps work. It collects core commands, collaboration workflows, and safe practices for managing infrastructure and application changes.

## Topics

- [Git basics and command reference](git-basics.md)
- [Branching and collaboration workflow](devops-workflow.md)

## Suggested practice

1. Initialize a local repository and make a few small commits.
2. Create a feature branch, make a change, and merge it into `main`.
3. Practice reviewing a diff before committing and resolving a simple merge conflict.
4. Use tags to mark a release and inspect the commit history.

Examples in this repository are intended for learning. Review commands before running them in a production repository.
